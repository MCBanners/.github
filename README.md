# MCBanners

MCBanners is a service that generates images and previews for Minecraft servers, resources, and community content.

It is used to create shareable visuals like server banners, mod/resource cards, and saved image links that can be embedded on websites, forums, and Discord.

---

## What you can do with it

- View Minecraft server information in a visual format  
- Generate banners for servers and player communities  
- Create preview cards for mods and plugins  
- Save and share generated images with simple links  
- Embed images in Discord, forums, and websites  

## Examples

- Server banner for a Minecraft server  
- Resource preview for a mod or plugin  
- Shareable image links for community posts  

---

## Status

MCBanners is actively running and available for public use.

It is designed to be fast, reliable, and easy to integrate into Minecraft communities.
